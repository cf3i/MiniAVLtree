# Overview

> 本文档回答：这个项目是什么？什么不做？

## 项目摘要

- 项目名称：MiniAVLtree-test（仓库目录名；项目元信息文件当前未配置）
- 一句话目标：提供一个基于 C++ 的最小 AVL 树实现，用于接收整数输入、完成平衡插入，并输出树的中序和前序遍历结果。
- 目标用户：需要学习、验证或手工调试 AVL 树插入与旋转逻辑的开发者或学生。
- 业务价值：用一个小型、可直接运行的示例集中展示自平衡二叉搜索树的核心机制，便于算法理解和回归验证。

## 范围定义

### In Scope

- [x] 基于整数值创建 AVL 树节点，并维护节点高度信息。
- [x] 支持 AVL 树插入操作，并在失衡时执行 LL、RR、LR、RL 旋转。
- [x] 支持按二叉搜索树规则查找指定整数节点。
- [x] 支持输出当前树的中序遍历和前序遍历结果。
- [x] 提供面向 issue 的回归测试约定，允许通过 `issue_test/*.sh` 脚本验证目标行为。 

### Out of Scope

- [x] 删除操作当前未实现；`remove` 仅有声明，代码中没有对应定义和可执行路径。
- [x] 泛型键类型、键值对载荷等通用容器能力当前未提供，节点仅保存 `int val`。
- [x] 独立库封装、对外 API 服务或图形界面当前未体现，现有入口是命令行读取整数并打印遍历结果。

## 核心概念

| 概念 | 定义 | 备注 |
| --- | --- | --- |
| `node` | AVL 树节点，保存整数值、高度以及左右子节点指针。 | 结构体中还声明了 `parent` 指针，但当前实现未使用。 |
| `AVLtree` | 树的核心封装，负责插入、查找、遍历、销毁和旋转调整。 | 当前 `main` 直接实例化并使用该类。 |
| 高度（`height`） | 记录节点子树高度，用于计算平衡状态并决定是否旋转。 | 通过 `height(node*)` 辅助函数读取。 |
| 旋转 | 在插入导致失衡时恢复 AVL 平衡的结构调整操作。 | 当前实现包含 `__LRotate`、`__RRotate`、`__LRRotate`、`__RLRotate`。 |
| Issue Test | 面向单个 issue 的回归脚本约定。 | 由 [issue_test/README.md](/Users/feic/Pjs/MiniAVLtree-test/issue_test/README.md) 定义命名和执行合约。 |
