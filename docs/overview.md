## 项目摘要

- 项目名称：（待填写，仓库当前无 README 或包管理元信息）
- 一句话目标：提供一个基于命令行输入的最小 AVL 树实现，并补充一个静态 HTML 可视化页面，用于观察插入后的树结构与遍历结果。
- 目标用户：需要学习、验证或手工测试 AVL 树插入和平衡逻辑的开发者、学生或演示使用者。
- 业务价值：以较小代码体量演示自平衡二叉搜索树的核心机制，同时提供浏览器可视化帮助理解旋转和平衡结果，便于教学、实验和回归验证。

## 范围定义

### In Scope

- 整数值 AVL 树结点的内存结构管理，结点包含值、高度和左右子指针。
- 基于递归插入的二叉搜索树构建。
- 通过高度差判断失衡并在插入后执行再平衡。
- 支持 `L`、`R`、`LR`、`RL` 四种旋转操作。
- 通过标准输入读取固定 10 个整数，并在每次插入后输出中序与前序遍历结果。
- 提供一个静态 HTML/JS 页面，用浏览器渲染整数序列对应的 AVL 树结构与遍历结果。

### Out of Scope

- 节点删除及删除后的再平衡当前未实现，`remove(int val)` 仅声明未落地。
- 泛型键值、字符串键值或其他非整数数据模型当前未提供。
- 文件持久化、数据库、网络 API 或复杂前后端联动当前未提供。

## 核心概念

| 概念 | 定义 | 备注 |
| --- | --- | --- |
| `node` | AVL 树结点，保存整数值、高度、左右孩子指针和父指针。 | 当前 `parent` 字段已定义，但现有插入/旋转逻辑未使用。 |
| `AVLtree` | 树容器，持有根结点并对外暴露插入、搜索、遍历和析构能力。 | 当前删除接口仅声明未实现。 |
| `height` | 结点高度信息，用于计算左右子树高度差并判断是否失衡。 | 通过 `height(node*)` 辅助函数读取。 |
| 旋转 | 为恢复平衡执行的局部结构调整，包括左旋、右旋、左右旋、右左旋。 | 当前平衡修复全部围绕插入流程展开。 |
| 遍历输出 | 用中序和前序遍历打印当前树结构。 | 通过标准输出展示每次插入后的结果。 |
